## O que é este projeto?

FlowTrack é uma aplicação de **gestão financeira pessoal** desenvolvida para o Tech Challenge da FIAP (Fase 02). O projeto combina:

- **Next.js 16** como shell (host)
- **4 microfrontends** independentes com **Webpack Module Federation**
- **Autenticação JWT** com cookies httpOnly
- **Docker** para containerização
- **Deploy cloud** (Vercel)
